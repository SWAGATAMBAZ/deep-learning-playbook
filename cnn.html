Why not just use an MLP on pixels?

🧒 In plain English

A 224×224 colour image has 150,528 numbers. A dense layer of 1,000 neurons would need 150 million weights, and it would have to learn "cat in the top-left" separately from "cat in the bottom-right". A CNN uses one small 3×3 filter, shares it across the whole image, and only looks at neighbouring pixels. That gives far fewer parameters and finds the pattern wherever it is.

Local connectivity

Each neuron looks at a small patch, because nearby pixels are related.

Weight sharing

The same filter is used everywhere, which cuts the parameter count enormously.

Translation equivariance

Shift the input and the feature map shifts with it. Pooling adds some translation invariance.

Hierarchy

Edges → textures → parts → objects as the receptive field grows with depth.

The output-size formula (asked constantly)

📐 Memorise this
out = ⌊ (W − K + 2P) / S ⌋ + 1

W = input size, K = kernel size, P = padding, S = stride. Parameters in a conv layer = (K × K × Cin + 1) × Cout. They do not depend on the image size.

Pooling, 1×1 convs and receptive field

  • Max pooling (2×2, stride 2) halves the spatial size and keeps the strongest activation, which gives a little robustness to small shifts. Modern nets often use stride-2 convs instead.
  • Global average pooling averages each feature map to a single number before the classifier. It replaced huge dense layers (fewer parameters, less overfitting).
  • 1×1 convolution mixes channels at each pixel. It's used to shrink or expand the channel count cheaply (the bottlenecks in ResNet and Inception).
  • Receptive field: the input region a neuron "sees". It grows with depth, stride and dilation. Two stacked 3×3 convs see 5×5 with fewer parameters than one 5×5 (that's VGG's insight).

📐 Why depthwise-separable convs are cheap

A standard K×K conv costs K²·Cin·Cout per pixel. Depthwise (one K×K filter per input channel) + pointwise (1×1 to mix channels) costs K²·Cin + Cin·Cout. With K=3 and Cout=256, that's about 8–9× fewer multiply-adds. It's the core trick of MobileNet, EfficientNet and ConvNeXt.

🧒 Why ResNet's skip connection works

Instead of asking each block to learn the whole transformation, the block only learns the correction F(x) to add to its input. If a layer isn't useful it can learn F(x)=0 and pass x through unchanged. The "+x" path also gives gradients a highway straight back to the early layers, so they don't vanish.

Transfer learning: the thing you'll actually do at work

🧒 In plain English

A model pre-trained on millions of images has already learned edges, textures and shapes. You keep that "visual cortex" and retrain only the last layer for your task, such as "is this a valid Aadhaar/PAN card?". It works with a few thousand labelled images instead of millions.

SmallYesFreeze the backbone and train only the head (feature extraction)

⚠️ Fine-tuning traps

Use a lower LR for the backbone (e.g. 1e-5) than for the new head (1e-3), or you'll wreck the pretrained features ("catastrophic forgetting"). Use the same normalisation (ImageNet mean/std) the model was pretrained with.

Interview Q&A

Input is 32×32×3, conv with 16 filters of 5×5, stride 1, no padding. Output shape and parameter count?

(32−5+0)/1+1 = 28, so the output is 28×28×16. Parameters = (5·5·3 + 1)·16 = 1,216.

Why do residual connections help?

(1) Gradient highway: ∂(F(x)+x)/∂x = F'(x) + 1, so the gradient never fully vanishes. (2) Easy identity: a block can learn F=0 and be skipped, so adding depth can't make things worse in principle. This solved the degradation problem where deeper plain nets trained worse.

CNN vs Vision Transformer?

CNNs have built-in inductive biases (locality, translation equivariance), so they're data-efficient and good for small or medium datasets and edge devices. ViTs have weaker biases and global attention from layer 1. They need large data or pretraining but scale better. In practice, use whichever pretrained backbone does best on your validation set.

What does a 1×1 convolution do?

It's a per-pixel linear layer across channels. It changes the channel count (bottleneck to save compute), adds non-linearity, and mixes channel information without touching spatial size.

You have 2,000 labelled images of damaged vs undamaged cars. Approach?

Transfer learning from an ImageNet backbone (EfficientNet/ResNet/ConvNeXt), heavy augmentation, freeze then gradually unfreeze with discriminative LRs, stratified CV, and track recall on "damaged". Add Grad-CAM to verify the model looks at the dent, not the background. If more is needed, use semi-supervised learning or self-supervised pretraining on unlabelled claim photos.

Max pooling vs average pooling?

Max keeps the strongest activation ("is the feature present anywhere here?") and is used between conv blocks. Average smooths and summarises. Global average pooling is standard just before the classifier.
