Cheat sheet: default hyperparameters that usually work

Optimizer

AdamW, lr 1e-3 (from scratch) / 2e-5 to 5e-5 (fine-tuning transformers), weight decay 0.01

Schedule

Linear warm-up for 5–10% of steps → cosine decay

Batch

32–256; gradient accumulation if memory is limited

Regularisation

Dropout 0.1–0.3, early stopping with patience 3–10

Activation / norm

ReLU/GELU; BatchNorm for CNN/MLP, LayerNorm for transformers

Precision

Mixed precision (bf16/fp16) and gradient clipping at 1.0
