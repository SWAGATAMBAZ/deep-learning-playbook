PyTorch coding drills

24 exercises that come up in DS / ML coding rounds: implement a layer, a loss, attention, a training-loop feature, or an evaluation metric from scratch. Every solution ships with assertions that compare against PyTorch or scikit-learn, and all of them were run and pass. Write your own version first, then reveal.

🎯 How to practise

Set a 15-minute timer per drill. Write it in a blank notebook without autocomplete, run the assertions, then compare with the solution. Redo the ones you missed three days later. Tick "solved" to track progress (saved in your browser).
