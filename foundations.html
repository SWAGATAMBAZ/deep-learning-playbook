Neural network foundations

A neural network is a stack of very simple functions. Each one is a weighted sum followed by a bend. Training means nudging the weights so the output's error goes down. Everything else in deep learning builds on that.

Machine learning vs deep learning

🧒 In plain English

Classic ML (logistic regression, XGBoost) needs you to hand-craft the features: "average spend over the last 7 days", "number of words in the complaint". Deep learning learns the features itself from raw-ish data such as pixels, words or click sequences, one layer at a time. Early layers learn simple patterns (edges, character n-grams) and later layers combine them into concepts (faces, "angry customer").

🎯 Interview point

"When would you not use deep learning?" Say: small tabular data, a need for strict interpretability (credit decisions under regulation), tight latency on CPU, or no unstructured signal. A tuned GBDT is the default baseline for tabular data.

The neuron: weighted sum + bend

🧒 In plain English

A neuron is a tiny voter. It looks at its inputs, gives each one an importance (weight), adds a personal bias, and then decides how strongly to "fire" (the activation). One neuron with a sigmoid is logistic regression. A network is thousands of these voters in layers, where each layer votes on the previous layer's votes.

📐 The maths
z = w1x1 + w2x2 + … + b = w·x + b   →   a = σ(z)

A whole layer is a matrix multiply: a = σ(Wx + b). Stacking layers gives ŷ = σ₃(W₃ σ₂(W₂ σ₁(W₁x))). Without the non-linear σ, the whole stack collapses into one big linear model, which is why activations are essential.

Loss functions: how wrong are we?

🧒 In plain English

The loss is a single number that scores how bad the predictions are. Training is just "make this number smaller". Which loss you pick depends on what kind of wrong you care about.

📐 Binary cross-entropy
L = −[ y·log(p) + (1−y)·log(1−p) ]

If the truth is fraud (y=1) and you predict p=0.01, the loss is −log(0.01) ≈ 4.6, a big penalty. Predict p=0.99 and the loss is ≈ 0.01. Cross-entropy punishes confident wrong answers hard. That is why it beats MSE for classification: MSE with a sigmoid gives tiny gradients exactly when the model is very wrong.

⚠️ Classic bug

nn.CrossEntropyLoss and BCEWithLogitsLoss expect raw logits. They apply softmax/sigmoid internally. Adding a softmax layer before them silently hurts training.

Gradient descent: walking downhill blindfolded

🧒 In plain English

You're on a foggy mountain and want to reach the valley (lowest loss). You can't see far, but you can feel the slope under your feet. So you take a step downhill, feel again, and step again. The gradient is the slope. The learning rate is your step size. Steps too big and you overshoot the valley; too small and you'll be there all year.

📐 Update rule
w ← w − η · ∂L/∂w

Batch GD uses all data per step (accurate but slow). Stochastic GD uses 1 sample (noisy). Mini-batch uses 32–1024 samples, which is the standard. The noise from mini-batches actually helps the model escape sharp minima and generalise better.

Backpropagation = the chain rule, applied backwards

🧒 In plain English

The output was wrong by some amount. Backprop walks backwards through the network asking each weight, "how much of this error is your fault?" Each layer passes the blame to the layer before it, scaled by how much it amplified the signal. Every weight then moves a little in the direction that reduces its share of the blame.

📐 Chain rule for a 2-layer net
∂L/∂W₁ = ∂L/∂ŷ · ∂ŷ/∂h · ∂h/∂z₁ · ∂z₁/∂W₁

It's a product of local derivatives. If each factor is < 1 (sigmoid's max is 0.25), the product shrinks exponentially with depth and you get vanishing gradients. If each is > 1, the product blows up and you get exploding gradients. ReLU, good initialisation, normalisation and residual connections all exist to keep this product close to 1.

🎯 Interview point

"What does loss.backward() do?" It traverses the computation graph autograd built during the forward pass, applies the chain rule, and accumulates the result into each parameter's .grad. That accumulation is why you must call opt.zero_grad() every step.

Interview Q&A

Why do we need non-linear activation functions?

A composition of linear maps is still linear: W₂(W₁x) = (W₂W₁)x. Without non-linearity, a 100-layer network is just linear regression. Non-linearities let the network bend the decision boundary and approximate any function (the universal approximation theorem).

Why ReLU over sigmoid in hidden layers?

(1) Its gradient is exactly 1 for positive inputs, so there are no vanishing gradients on that side. (2) It's cheap to compute. (3) It gives sparse activations. The downside is dead neurons when z < 0 always; Leaky ReLU or GELU fix that.

Why cross-entropy instead of MSE for classification?

Cross-entropy with a sigmoid/softmax gives the clean gradient (p − y), which is large when the model is confidently wrong. MSE with a sigmoid multiplies by σ'(z), which is near 0 at saturation, so learning stalls exactly when the error is biggest. Cross-entropy is also the maximum-likelihood loss for a Bernoulli/categorical output.

What happens if you initialise all weights to zero?

Every neuron in a layer computes the same output and gets the same gradient, so they stay identical forever (the symmetry problem). The network effectively has one neuron per layer. Use random initialisation scaled by fan-in: Xavier/Glorot for tanh, He/Kaiming for ReLU.

Batch vs stochastic vs mini-batch gradient descent?

Batch uses the full dataset per step: exact gradient, slow, memory-heavy. SGD uses one sample: noisy and fast. Mini-batch (32–1024) is the practical middle ground. It uses GPUs efficiently, and its noise acts as a regulariser.

Why is depth better than width?

Depth lets the model compose features hierarchically (edges → shapes → objects), which can represent some functions with exponentially fewer parameters than a single wide layer. Deeper networks are harder to train, which is why ResNets, normalisation and good initialisation matter.

What is an epoch, a batch and an iteration?

Batch = the samples in one forward/backward pass. Iteration = one weight update. Epoch = one full pass over the training data. So iterations per epoch = N / batch_size.
