Attention & Transformers

The transformer is the architecture behind BERT, GPT, ViT and modern recommenders. Its core idea is simple: every token looks at every other token and decides how much to borrow from each.

Intuition: a soft dictionary lookup

🧒 In plain English

In "The bank approved the loan because it was low-risk", what does "it" mean? You resolve it by looking back at the other words and focusing on "loan". Attention does exactly this. Each word sends out a Query ("what am I looking for?"), every word advertises a Key ("what I contain"), and the matches decide how much of each word's Value (its actual content) gets blended into the new representation of "it".

Think of a library: your query is the search phrase, keys are the book titles, values are the books' contents. A normal dictionary returns one exact match; attention returns a weighted blend of all values, weighted by how well each key matches.

The maths: scaled dot-product attention

📐 The one equation to write on the whiteboard
Attention(Q, K, V) = softmax( QKT / √dk ) · V
  1. Project each token embedding x into three vectors: Q = XWQ, K = XWK, V = XWV.
  2. QKT: dot-product similarity of every query with every key, giving an n×n score matrix.
  3. ÷ √dk: if q and k have unit-variance entries, q·k has variance dk. Dividing keeps the scores around unit variance so softmax doesn't saturate.
  4. softmax over each row turns scores into weights that sum to 1.
  5. × V: each output is a weighted average of the value vectors.

Multi-head attention

🧒 In plain English

One attention pattern can't capture everything. One head might track "which noun does this pronoun refer to", another "which adjective describes this noun", another "the previous word". Multi-head attention runs h small attentions in parallel (dk = dmodel/h each), concatenates them and mixes with a linear layer. The total compute is about the same as one big head.

Positional encoding: attention has no sense of order

Attention is permutation-invariant: shuffle the words and each token gets the same output, just in a different order. So we inject position information:

  • Sinusoidal (original paper): PE(pos, 2i) = sin(pos/100002i/d). Fixed, and can extrapolate to longer sequences.
  • Learned absolute embeddings (BERT, GPT-2).
  • RoPE (rotary; used in LLaMA and most modern LLMs): rotates Q and K by a position-dependent angle, so their dot product depends on relative distance.
  • For transactions, add time-delta encodings. The gap between events matters, not just their order.

The transformer block

Tokens exchange information.

Add & LayerNorm

Residual connection x + Attn(x). Modern models use pre-norm: x + Attn(LN(x)).

3

Feed-forward network

A 2-layer MLP (d → 4d → d, GELU) applied to each token separately. This is where much of the "knowledge" is stored.

4

Add & LayerNorm

Another residual. Stack N blocks (12 in BERT-base).

🎯 Masks

Padding mask: ignore pad tokens. Causal (look-ahead) mask: in a decoder, token t can only attend to tokens ≤ t. The future scores are set to −∞ before the softmax. This is what makes GPT autoregressive.

Cost and the tricks that fix it

  • Self-attention is O(n²·d) in time and O(n²) in memory for sequence length n. Doubling the context quadruples the attention cost.
  • FlashAttention: exact attention computed in tiles to avoid storing the n×n matrix. Much faster, with the same result.
  • KV cache: at inference, store past keys and values so each new token costs O(n) instead of recomputing everything.
  • Sparse, sliding-window and linear attention; GQA/MQA (share K and V across heads to shrink the KV cache).

Interview Q&A

Why divide by √dk?

For random q, k with zero-mean unit-variance components, q·k has variance dk. With dk=64 the scores have a std of about 8, so softmax becomes nearly one-hot and its gradients are close to zero. Scaling by √dk brings the variance back to about 1, which keeps the softmax in a range with useful gradients.

What's the difference between self-attention and cross-attention?

In self-attention, Q, K and V all come from the same sequence. In cross-attention, Q comes from one sequence (the decoder) and K, V from another (the encoder output, or image features in multimodal models).

Why multi-head instead of one big head?

Each head learns a different relation in a different subspace (syntax, coreference, position). A single head averages all of them into one distribution. The cost is the same because each head uses d/h dimensions.

BERT vs GPT in one breath?

BERT is an encoder trained with masked language modelling. It sees context in both directions, so it's best for understanding tasks (classification, NER, embeddings). GPT is a decoder trained on next-token prediction with a causal mask, so it's best for generation and general prompting.

What is the complexity of self-attention and how do LLMs handle long context?

O(n²d) compute and O(n²) memory. Mitigations: FlashAttention (IO-aware exact attention), sliding-window or sparse attention, GQA to shrink the KV cache, RoPE scaling to extend positions, and retrieval (RAG) instead of stuffing everything into the context.

Why are residual connections and LayerNorm essential in transformers?

Residuals give gradients a direct path through dozens of layers and let each block learn a refinement. LayerNorm stabilises activation scale per token. Pre-norm (LN before the sub-layer) trains more stably at depth without careful warm-up.

How would you use a transformer for transaction fraud?

Treat each customer's recent transactions as tokens (embedding of MCC, merchant, amount bucket, channel, plus a time-delta encoding). Optionally pretrain with masked-transaction prediction on unlabelled history. Use the [CLS]/pooled output plus current-transaction features to predict fraud. Watch latency: cache per-customer states, or distil into a smaller model.
